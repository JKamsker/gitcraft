# Shared-owner caller migration (WIP prerequisite)

Watched Git, line streaming, local/remote AI and the unreachable-commit scan now route through the shared process service. Stopper state contains only cancellation, never process numbers. The public raw-PID remote stop/spawn APIs and host-wide stop selector have been removed. Streaming removes its exact-nonce endpoint handshake before output capture, preserves both-output callbacks and partial output, and bounds its consumer queue/line buffers. Dedicated bounded cleanup service capacity prevents circular waits behind the transports being stopped. Cleanup errors retain an explicit unconfirmed result instead of claiming that lost SSH means stopped. User stdin remains separate from the open controller lease. The process service keeps its existing Command/Options interface; stop_remote now returns Result to preserve acknowledgement failures.

Pure gates: `CARGO_BUILD_JOBS=2 cargo +1.95.0 check --locked --all-targets` passed (baseline native warnings plus the not-yet-used recovery record reader). `CARGO_BUILD_JOBS=2 cargo +1.95.0 test --locked --lib remote::supervisor::recording_tests -- --nocapture` passed 3 recording/parser tests, including every split of the actual streaming marker. Python 3 recording tests and Perl recording mode each passed 3 injected-owner gates. Formatting passed. No real cancellation/process/SSH/WSL/Windows tests ran.

This is WIP and not safe-suite authorization: bisect still contains the legacy selector and needs durable receipt recovery; local Darwin zombie-only EPERM needs the live-anchor correction; native Windows durable bisect supervision is pending. The old direct raw-PID tests were replaced with production owned-dispatch tests, but those replacements have only compiled and have not run. No independent review has occurred. The seven issue feature ideas remain unimplemented in this branch.
