# Packaged local Unix live anchor (WIP prerequisite)

Local Unix execution now starts a small C anchor compiled for the target at build time and embedded in gitcraft-os. The original std::process::Command still applies cwd, environment (including env_clear), stdio and a fresh group; an async-signal-safe pre_exec handoff execs the packaged anchor with separately preserved argument words. The helper forks/execs the user command, reports its wait status over a private close-on-exec pipe, closes output, and stays alive until the owner's final group signal and reap. This addresses Darwin's zombie-only group interval without ignoring EPERM or reaping then signaling a stale number. The helper is installed in a fresh mode-0700 directory; it needs no compiler/interpreter on the user's system. Startup errors are explicit; no shell/raw-group fallback exists.
